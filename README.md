# AuraWave — Native Windows Desktop Audio Companion

AuraWave is a lightweight, native C# / WPF Windows desktop audio companion that renders a genuinely transparent, click-through real-time audio visualization over any desktop application alongside an independent floating **Now Playing** widget.

## Global Keyboard Shortcuts
- `Alt + C` : Toggle Waveform Click-Through
- `Alt + A` : Show / Hide AuraWave Components
- `Alt + S` : Open / Focus Settings Window
- `Alt + M` : Cycle Presentation Mode
- `Alt + W` : Toggle Waveform Visibility Independently
- `Alt + P` : Toggle Now Playing Visibility Independently
- `Ctrl + Alt + E` : Enter / Exit Interactive Edit Mode
- `Ctrl + Alt + Plus` : Increase Selected Widget Size (+10%)
- `Ctrl + Alt + Minus` : Decrease Selected Widget Size (-10%)
- `Alt + Q` : Quit AuraWave
